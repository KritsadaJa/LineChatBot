# Solar Rooftop Tax Deduction (2026-2028)

## 💰 Benefit Summary
**Deduction Limit**: Up to 200,000 THB  
**Period**: March 3, 2026 - December 31, 2028  
**Type**: Actual cost deduction (max 200,000 THB).

---

## ✅ Eligibility Conditions

### 1. System Requirements
- Must be an **On-grid** system.
- Size not exceeding **10 kWp** per house.

### 2. Documentation
- Must use **e-Tax Invoice** only.
- Buyer name, meter owner, and taxpayer must be the same individual.

### 3. Eligibility Type
- **Individuals** only (Corporations use depreciation instead).

## 🔌 Selling Electricity Back (Net Billing)
**Current Status (2026)**: Residential users **cannot** currently sell electricity back because current quotas are full. NextE designs systems for **Self-Consumption** to maximize savings during peak daytime rates.
